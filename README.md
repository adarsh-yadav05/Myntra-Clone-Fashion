# Myntra Clone

## E-Commerce Fashion Website

Myntra Clone is a responsive e-commerce fashion website inspired by Myntra, developed to provide a modern online shopping experience. The project focuses on frontend development, responsive UI design, product browsing, cart management, and wishlist functionalities using Local Storage.

The website allows users to explore products, search categories, add items to cart or wishlist, and experience a clean and interactive shopping interface across multiple devices.

---

## Features

* Responsive E-Commerce UI Design
* Product Listing & Category Filtering
* Search Functionality
* Add to Cart Feature
* Wishlist Management
* Local Storage Integration
* Mobile & Desktop Compatibility
* Interactive User Interface
